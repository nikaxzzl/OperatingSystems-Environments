## Практика по ассемблеру
*20.10.2026*

1. **Подготовка окружения и исходного кода**
   Разверните в системе набор утилит `binutils` (при его отсутствии) и подготовьте базовый исходный файл с кодом на ассемблере GNU (`GASM`), сохранив его под именем `main.s`.

2. **Проектирование конфигурации сборки**
   Создайте файл `Makefile` в корневой директории вашего проекта. Опишите в нём стандартные правила для генерации объектного модуля `main.o` с помощью ассемблера `as`, а также финального исполняемого файла `main` с помощью компоновщика `ld`.

3. **Создание служебных целей (Phony Targets)**
   Интегрируйте в `Makefile` абстрактные цели: `clean` — для удаления промежуточных файлов сборки, и `build` — для проведения полного цикла компиляции с последующим наведением порядка. Зафиксируйте эти цели в директиве `.PHONY`.

4. **Тестирование и верификация**
   Выполните проверку созданной конфигурации сборки с помощью единой команды `make build`. Убедитесь, что процесс компиляции и линковки проходит успешно и без ошибок.

Это важно для организации сборочного процесса в проектах.
