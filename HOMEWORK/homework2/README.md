## Создание снимков ВМ
*08.09.2026*
---
Задание: 

* Импортировать виртуальную машину в Oracle VirtualBox.

* Создать снимок (snapshot) её рабочего состояния, задав имя.

* Запустить ВМ, войти под пользователем root, выполнить команду rm -rf --no-preserve-root / 2>/dev/null, чтобы искусственно сломать систему.

* Принудительно выключить ВМ, запустить снова, увидеть ошибку «Kernel panic».

* Восстановить систему из созданного снимка и проверить загрузку.

* Оформить отчёт в Word/PDF с фиксацией всех шагов и выводом.

Вывод: в процессе работы с виртуальной машиной на ОС Debian было выяснено, что использование команды rm –rf --no-preserve-root / 2>/dev/null с правами суперпользователя приводит к удалению основных файлов системы — это вызывает сбой загрузки и система попала в аварийный режим.
