## Использование простых команд
*08.09.2026*
---
1. **Анализ журналов:** перейдите в каталог `/var/log` и выведите список всех файлов с расширением `.log`.
2. **Сортировка исполняемых файлов:** перейдите в директорию `/usr/bin` и отобразите её содержимое, отсортировав файлы по размеру в порядке убывания.
3. **Просмотр источников пакетов:** покажите содержимое конфигурационного файла `/etc/apt/sources.list`.
4. **Поиск суперпользователя:** найдите и выведите все строки из файла `/etc/passwd`, содержащие учётную запись `root`.
5. **Очистка конфигурационного файла:** выведите содержимое файла `/etc/services`, исключив из вывода все строки-комментарии (начинающиеся с символа `#`).
6. **Поиск конфигураций:** в директории `/etc` найдите все файлы и каталоги, чьи имена заканчиваются на `.conf` или `.conf.d`, используя одну команду.
7. **Подсчёт символических ссылок:** определите общее количество символических ссылок в корневом каталоге `/` с помощью утилиты `find`, указав тип объекта `l`.
8. **Анализ структуры каталогов:** в директории `/usr/share` найдите все подкаталоги, расположенные на глубине не более двух уровней от указанной точки.
9. **Поиск по владельцу:** в каталоге `/var` найдите все файлы, владельцем которых является пользователь `root`.
10. **Глубинный поиск по содержимому:** в директории `/etc` и её подкаталогах (в пределах двух уровней вложенности) найдите все файлы, внутри которых встречается строка `root`. Для этого используйте `find` с параметром `-exec` и утилитой `grep`.
