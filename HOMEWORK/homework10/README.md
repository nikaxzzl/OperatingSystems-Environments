### Практическое задание: Работа с консольным мультиплексором tmux

1. **Знакомство с инструментом**
   Установите и запустите утилиту `tmux`. Разберитесь в ключевых отличиях между окном мультиплексора и стандартной сессией терминала.

2. **Управление окнами и запуск Vim**
   Создайте новое окно внутри сессии (`Ctrl+B`, затем `C`), присвойте ему имя `Text` и откройте в нём текстовый редактор `vim`.

3. **Написание и запуск скрипта**
   В редакторе `vim` напишите сценарий на Python, который будет циклически фиксировать количество секунд, прошедших с момента его старта, и записывать каждое новое значение с новой строки в файл `test.txt`. Запустите этот скрипт на выполнение.

4. **Мониторинг файлов**
   Вернитесь в самое первое окно мультиплексора (`Ctrl+B`, затем `0`). Организуйте непрерывное отслеживание размера файла `test.txt` в реальном времени, используя утилиту `watch`.

5. **Завершение процессов и закрытие вкладок**
   Остановите работу Python-скрипта и утилиты `watch`. Переключитесь во второе окно (`Ctrl+B`, затем `1`) и корректно закройте его с помощью команды `exit`.

6. **Горизонтальный сплит и работа с утилитами**
   Разделите текущую рабочую область по горизонтали (`Ctrl+B`, затем `%`). В правой панели выполните установку системного информера `fastfetch`, после чего запустите его в левой панели. По окончании закройте правую панель.

7. **Вертикальный сплит и управление панелями**
   Разделите экран по вертикали (`Ctrl+B`, затем `"`). Самостоятельно протестируйте различные варианты деления рабочей области, после чего последовательно закройте все созданные панели.
