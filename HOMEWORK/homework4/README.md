## Практика по простым командам 2
*18.09.2026*
---
1. **Подготовка рабочего окружения**
   Создайте в домашней директории каталог `work`, перейдите в него и выведите на экран полный путь до текущего местоположения.

2. **Инициализация файла**
   Создайте пустой файл с именем `file.txt`, используя команду `touch`.

3. **Наполнение файла текстом**
   Запишите в `file.txt` первые два абзаца из книги «Гарри Поттер». Каждое предложение должно располагаться на новой строке. Для добавления строк используйте команду `echo` с перенаправлением вывода (`>>`).

4. **Переименование и проверка**
   Смените имя файла с `file.txt` на `book.txt` и просмотрите его содержимое, чтобы убедиться, что текст был добавлен корректно.

### Поиск и анализ текста

5. **Извлечение данных по фильтру**
   Найдите в файле `book.txt` все предложения, содержащие слово `was`, и сохраните результат в новый файл `was.txt`.

6. **Комбинирование и подсчёт**
   Объедините содержимое файлов `was.txt` и `book.txt` и подсчитайте, сколько раз в полученном тексте встречается буква `n`. Для этого используйте конвейер команд с `grep` и `wc`.
