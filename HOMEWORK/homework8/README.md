## Практика по командам администрирования 2
*30.30.2026*
---
1. Давайте подключим к виртуальной машине адаптер, который позволит
обмениваться данными между гостевой машиной и хост-машиной. Для
этого в настройках виртуальной машины нужно активировать второй
адаптер с типом Виртуальный
адаптер и именем VirtualBox
Host-Only Ethernet Adapter
2. Введите команду ip address. Что вы увидели?
3. Установите на третьем адаптере любой незанятый адрес из той же
подсети, что и ваша хост-машина. По умолчанию, для виртуального
адаптера VirtualBox выделена сеть 192.168.56.0, а сама хост машина
имеет адрес 192.168.56.1
4. Проверьте связь с самим собой — то есть с адресом, который вы
выставили на адаптере.
5. Теперь попробуйте выполнить проверку связи из хост-машины в гостевую путем использования командной строки на операционной системе хост-машины.
---

Я научилась задавать IP адрес, также проверять связь, как из гостевой системы в хост-машину, так и из хост-машины в гостевую через командную строку Window и подключать новый адаптер. Правильная настройка сети позволяет быстро устанавливать соединение между машинами и делает дальнейшую работу легче с виртуальной машиной.
