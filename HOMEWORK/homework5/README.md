## Практика по командам администрирования
*19.09.2026*
---
* **Визуализация иерархии процессов:** вывести структуру запущенных процессов в виде дерева с отображением связей «родитель — потомок», подобрав для этого соответствующие ключи
* **Фильтрация по владельцу:** обнаружить все активные процессы в системе, которые были запущены не от имени вашей текущей учётной записи (`root`).
* **Мониторинг прожорливых задач:** определить топ-5 процессов, использующих наибольший объём оперативной памяти, ограничив вывод с помощью утилиты `head`.
* **Поиск фоновых задач:** сформировать и вывести список всех процессов, работающих в фоновом режиме.
* **Анализ ключей копирования:** открыть справочное руководство для команды `cp` и найти аргумент, который отвечает за сохранение прав доступа, владельца и временных меток при дублировании файлов.
* **Расширенный поиск в мануалах:** изучить справку `man` и определить флаг, позволяющий искать документацию по ключевым словам, а не по точному названию утилиты.
* **Альтернативный поиск справок:** найти команду с аналогичным функционалом контекстного поиска и с её помощью собрать все страницы руководств, связанные со словом «copy».

Так же научилась искать команды через справочник по ключевым словам. Это помогает быстрее находить нужные утилиты и разбираться в системе.
