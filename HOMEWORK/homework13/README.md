## Функции в Bash
*19.10.2026*
1. **Теоретический анализ механизмов завершения**
   Проанализировать и подробно описать принципиальные различия между использованием встроенных команд `exit` и `return` при написании сценариев и функций в Bash.

2. **Функция динамического перенаправления потоков**
   Разработать Bash-функцию, способную отправлять текстовые данные в произвольный канал вывода, который задаётся пользователем через аргумент (стандартный вывод `stdout`, поток ошибок `stderr` или указанный файл).

3. **Служебная функция сбора системных метрик**
   Создать функцию для диагностики системы, которая принимает на вход ключевое слово параметра (например, `pwd`, `user`, `version` и т.д.) и возвращает соответствующую информацию. Продемонстрировать практические примеры её вызова.

4. **Интерактивная утилита чтения переменных через eval**
   Написать функцию, которая принимает имя переменной в виде строки и выводит её текущее значение с помощью механизма `eval`. Интегрировать эту функцию в интерактивную программу, непрерывно обрабатывающую пользовательский ввод вплоть до получения сигнала завершения `Ctrl+D` (EOF).
